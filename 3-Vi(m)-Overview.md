# Vi(m) Commands
<u>Exit</u>  
`:w` save file  
`:wq` save and quit  
`:q!` force quit

<u>Insert</u>  
`o` open new line  
`i` insert mode (before carat)  
`a` add (after carat)  
`Esc` command mode

<u>Cursor Nav</u>  
`h` left  
`l` right  
`k` up  
`j` down  
`b` word/token left  
`w` word/token right  
`0` jump to first char on the line  
`$` jump to last char on the line  
`e` move to the end of the work 

<u>Commands</u>  
`x` delete  
`u` undo  
`r` replace  
`y` "yank" copy  
`p` put

<u>Modes</u>  
Command (default): use nav and editing key commands (Esc)  
Insert mode: type stuff (i, a, or o)  
Ex mode: exit (colon from command mode)
